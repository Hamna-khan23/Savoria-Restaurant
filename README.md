# Savoria Restaurant & Café

Savoria Restaurant & Café is a modern and responsive frontend website designed for a premium café and restaurant. The website provides visitors with a clean and elegant online experience where they can explore the restaurant, browse the menu, view food and restaurant images, learn more about the café, and get in touch through the contact section.

## About the Project

This project was developed as a frontend web development project with a focus on responsive design, modern user interface, smooth navigation, and interactive elements.

The website features a warm and elegant restaurant-inspired design using dark coffee brown, warm gold, and cream tones. It is designed to provide a consistent and user-friendly experience across desktop, tablet, and mobile devices.

## Features

- Responsive and mobile-friendly design
- Modern café and restaurant interface
- Attractive home page with hero section
- About page with restaurant information
- Menu page with categorized food items
- Interactive menu category filtering
- Gallery page for food and restaurant images
- Contact page with contact information and contact form
- Reservation call-to-action section
- Responsive navigation bar
- Consistent footer across all pages
- Smooth hover effects and UI transitions
- Bootstrap Icons for visual elements
- Clean and organized frontend design

## Menu Filtering

The Menu page includes an interactive category filtering system developed using JavaScript.

Visitors can filter menu items by:

- All
- Starters
- Main Course
- Desserts
- Drinks

The menu items are filtered dynamically without requiring the page to reload.
